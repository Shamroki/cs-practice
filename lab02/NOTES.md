Гит - локальный проект на пк, а гитхаб это удалённый репозитарий , который работает как облако
Использованные команды: git diff - даёт посмотреть внесённые изменения , git status - показывает статус папки и индекса , git deff --staged  - показывает разницу между индексом и последним коммитом
Ветка гит указатель на цепочку коммитов. При коммите указатель ветки сдвигается вперёд. Слияние объединяет изменения из одной ветки в другую.
